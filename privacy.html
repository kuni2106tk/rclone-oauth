Privacy Policy

Last updated: October 25, 2026

1. Purpose

This application is a personal integration using rclone to access Google Drive from a Linux computer. It is not offered as a public service.

2. Data Access

The application accesses Google Drive files and metadata only as necessary to perform file operations requested by the account owner.

3. Data Storage

Authentication credentials are stored locally in the user's rclone configuration. Files may also be temporarily cached on the user's computer. This website does not receive or store Google Drive files or authentication tokens.

4. Data Sharing

The application does not intentionally share Google Drive data with third parties. Google Drive API requests are processed by Google.

5. Data Retention and Deletion

Local authentication credentials and cached files can be deleted by the account owner. Google account access can be revoked through Google Account security settings.

6. Security

Access is authorized through Google's OAuth 2.0 system. The account owner is responsible for securing the local computer and its authentication credentials.

7. Contact

This is a personal-use integration. Project information is available through its associated GitHub repository.
