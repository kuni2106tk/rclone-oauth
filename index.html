Personal rclone Google Drive Integration

This application is a personal integration using rclone to access Google Drive from a Linux desktop.

Purpose

The application allows the account owner to access, create, edit, and manage files in their own Google Drive using the rclone command-line tool.

Data Usage

Google Drive data is accessed only for the account owner's personal file management. This website does not collect Google Drive files or authentication credentials.

Privacy

Privacy Policy

This is an independently configured personal integration and is not affiliated with Google or the rclone project.
